Quick & Dirty: Fast-Track Install

Kein langes Einlesen. Hier ist das komplette All-in-One Paket: 1 Klick zu HACS, 1 Klick zur Ressource, YAML rein und Slicer-Profile rüberkopieren. Knopf drücken und losdrucken.

Gefällt dir das Projekt?
Schritt 1: HA Dashboard
🏠

Home Assistant in 60 Sekunden

Lovelace Dashboard & Integration
  1. Integration öffnen: Klicke auf den Button, um HACS zu öffnen und ha-snapmaker-u1-card herunterzuladen:
  2. Assets ablegen: Lade u1-fusion-showcase.u1.js herunter und speichere es in /config/www/snapmaker-u1/showcase/.
  3. Ressource anlegen: In HA unter Einstellungen → Dashboards → ⋮ (oben rechts) → Ressourcen als /local/snapmaker-u1/showcase/u1-fusion-showcase.u1.js (JavaScript-Modul) eintragen:
  4. Dashboard YAML einfügen: Neues Dashboard erstellen → Raw-Konfigurations-Editor öffnen → u1_dashboard_complete.yaml reinkopieren. Fertig!
📋 Dashboard YAML kopieren
Schritt 2: OrcaSlicer
🔪

OrcaSlicer Profile & 19 Filamente

Scarf Seams & 12.000 mm/s² Travel

Kopiere die Ordner process/, filament/ und machine/ direkt in dein OrcaSlicer-Benutzerverzeichnis:

🪟 Windows:
%APPDATA%\OrcaSlicer\user\default\
🍎 macOS:
~/Library/Application Support/OrcaSlicer/user/default/
📦 Komplettes ZIP herunterladen Einzeldruckprofile ansehen →
Schritt 3: Plugin
🧩

Set & Send Plugin (LayerLab)

Pre-Print Pop-up, Mesh & Spulenmapping

Schaltet den nativen Snapmaker Vor-Druck Dialog in Vanilla OrcaSlicer frei:

%APPDATA%\OrcaSlicer\orca_plugins\set_and_send.py\set_and_send.py

1 Datei ablegen → In OrcaSlicer Plugins aktivieren → Vor jedem Druck öffnet sich das Menü für 11×11 Mesh, Werkzeugkopf-Zuordnung und Filter-Steuerung!
