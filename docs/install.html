Install the Snapmaker U1 dashboard

Start here if Home Assistant can reach your U1. Setup time depends on which dependencies you have installed.

If HACS is new to you, follow the official setup for your installation type.

  1. Install Ironoxx’s integration in HACS, restart HA and add Snapmaker U1 Card under Settings → Devices & services.
  2. Install the six frontend dependencies in HACS: button-card, card-mod, slider-entity-row, vertical-stack-in-card, apexcharts-card, config-template-card.
  3. Copy the three files below to /config/www/media/snapmaker-u1/showcase/. Under Settings → Dashboards → Resources, register /local/media/snapmaker-u1/showcase/u1-fusion-showcase.u1.js as a JavaScript module.

    u1-fusion-showcase.u1.js · studio.png · close-up.png

  4. Paste the dashboard YAML into the Raw configuration editor of a new dashboard. Map the sample entity IDs before using the controls.

Install with an AI assistant

Copy the prompt into an assistant with Home Assistant admin and file access. It installs the dashboard and checks what is running.

Show installation prompt 
Install the Snapmaker U1 Community Dashboard and its custom Lovelace card in my Home Assistant. Carry out the installation using the Home Assistant admin/API, HACS and file-access tools available to you. Reply in my language.

1. Read the installation guide: https://github.com/Reaper2507/snapmaker-u1-homeassistant/blob/main/homeassistant/README.md
2. Check my Home Assistant version, HACS and the Snapmaker U1 Card integration by Ironoxx. Install missing prerequisites when your tools allow it. Discover the configured Snapmaker U1 and its entities. If setup requires the printer address, authentication or an integration step you cannot perform, ask me for that exact item and continue with independent steps.
3. Install or verify the six required Lovelace cards: button-card, card-mod, slider-entity-row, vertical-stack-in-card, apexcharts-card and config-template-card. Check their registered resources.
4. Download these files and place all three under /config/www/media/snapmaker-u1/showcase/
   https://raw.githubusercontent.com/Reaper2507/snapmaker-u1-homeassistant/main/homeassistant/www/u1-fusion-showcase.u1.js

   Register /local/media/snapmaker-u1/showcase/u1-fusion-showcase.u1.js as a JavaScript module. Verify the files are served and avoid registering a duplicate resource.

   Map the example entity IDs to my configured Snapmaker U1. Import the three views into a separate Snapmaker U1 dashboard. Reuse this project dashboard on a retry if you can identify it reliably. Back up a dashboard before modifying it and keep unrelated dashboards and resources intact.
6. Read back the dashboard and resource, then verify the three views and passive telemetry (printer status, temperatures, camera and progress).
